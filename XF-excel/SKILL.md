# XF Excel 表格生成

一键生成高考志愿填报完整 Excel 工作簿，四张表 + 一张图。

## 生成内容

| Sheet | 内容 |
|-------|------|
| 冲稳保总览 | 院校、专业、三年分数、学费、差距，红黄绿三色标注 |
| 近三年趋势 | 分数变化方向+安全评估（🟢安全/🟡接近/🔴危险） |
| 院校详情 | 核心优势+注意事项，决策参考 |
| 费用概算 | 学费+住宿+生活费，四年总计+ROI评估 |
| 分数走势图 | 柱状图对比三年分数+你的位置线 |

## 使用方式

### 1. 准备数据（JSON格式）

```json
{
  "user": {
    "province": "上海",
    "type": "政史地",
    "score": 538,
    "batch_line": 503,
    "comprehensive": 538
  },
  "targets": [
    {
      "school": "郑州科技学院",
      "major": "视觉传达",
      "tier": "冲",
      "score_2023": 423,
      "score_2024": 428,
      "score_2025": 432,
      "tuition": 16000,
      "pros": "省内认可度高，设计类专业有积淀",
      "cons": "分数线略高，2025年可能上涨"
    }
  ]
}
```

### 2. 运行脚本

```bash
python scripts/generate.py data.json
```

### 3. 交付文件

生成的 `.xlsx` 文件路径告知用户下载。

## 格式规范

- 字体：微软雅黑，标题 16 号蓝色加粗，正文 10 号
- 配色：冲=浅红、稳=浅黄、保=浅绿
- 首行冻结，方便滚动
- 列宽自适应
- 数字前 `-` 红色加粗，`+` 绿色
- 学费千分位格式（¥16,000）

## 数据来源

优先从同仓库其他技能获取：
- `gaokao-admission-table` → 近三年分数数据
- `XF-rational` → 院校优劣分析
- `XF-gaokao` → 冲稳保判断

然后组装 JSON 调用生成脚本。

## 输出文件

生成的 .xlsx 文件存储在用户指定路径，可直接双击打开（关联 Excel/WPS）。

生成后自动告知文件路径，用户点击路径即可打开。

## 输出铁律

- 生成后告知文件路径
- 一句话说明表里有什么
- 不做多余解释
