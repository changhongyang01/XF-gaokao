# XF-rational

XF 风格理性决策分析——不讲情怀，只翻底牌。

## 核心能力

六张底牌逐项翻：
1. 录取概率 — 能不能进
2. 就业实况 — 四年后能不能找到工作
3. 地域账 — 在哪儿混
4. 经济账 — 花多少挣多少
5. 个人匹配 — 适合你吗
6. 长期账 — 十年后还能靠这个吃饭吗

同时纳入大环境趋势（AI冲击、行业冷暖、人口变化）给出综合判断。

## 示例

> 我河南文科650，在人大法学、复旦经济、武大法学之间纠结

> 帮我把郑大计算机和西电通信做个对比分析

> 我家境困难，选护理还是会计？

## 联动

与 `XF-gaokao` 和 `gaokao-admission-table` 组成完整决策链：
