# 高考录取近三年对照表格生成

为高考志愿填报提供数据支撑，将目标院校/专业的近三年录取情况整理为直观对比表格。

## 数据维度

每张表格应包含以下核心字段：

### 普通类
| 维度 | 说明 |
|------|------|
| 院校名称 | 全称 |
| 专业名称 | 具体专业 |
| 年份 | 2023 / 2024 / 2025 |
| 批次 | 本科一批/二批/专科 |
| 最低录取分 | 当年最低投档分 |
| 最低位次 | 省排名 |
| 平均分 | 录取平均分 |
| 招生人数 | 该专业在上海招生计划数 |
| 线差 | 分数与批次线差值 |

### 艺术类（美术）
| 额外维度 | 说明 |
|----------|------|
| 文化课最低分 | 投档文化分 |
| 专业课最低分 | 统考分 |
| 综合分最低 | 综合投档分 |
| 综合分计算方式 | 各省公式不同，需标注 |

### 趋势指标（自动计算）
- **位次变化**：三年位次上升/下降趋势
- **分数波动**：三年分数最大差值
- **招生变化**：扩招还是缩招
- **安全系数**：当前分数 vs 三年最高分的差距

## 内置数据参考

生成表格时，优先从同仓库 `XF-gaokao/references/admission-data.md` 获取以下数据：

- 各省批次线（确定用户分数在哪个批次）
- 院校位次范围（判断冲稳保）
- 艺术类综合分公式（计算用户综合分）
- 民办本科参考分数和学费

若用户省份/院校数据不在参考文件中，则如实告知并使用用户提供的数据。

## 新高考适配

表格中文/理列替换为首选科目，批次线改为特招线/本科线。

## 数据声明

表格中所有分数必须在表头或脚注标注可靠性：

| 标注 | 含义 |
|------|------|
| ★★★ | 官方公布的精确数据 |
| ★★☆ | 基于位次反推，±3 分 |
| ★☆☆ | 趋势估算，±5 分以上 |

无标注的表格为估算值，必须提醒用户至省教育考试院核实。

## 工作流程

### 1. 确认查询范围
询问用户并确认：
- **省份**（不同省政策不同）
- **科类**：首选物理/首选历史、艺术类（美术/音乐/舞蹈/播音等）
- **分数/位次**：用户的文化课分、专业课分（艺术类）、综合分、省排名
- **目标院校**：有明确意向学校，还是需要推荐

### 2. 获取数据

按优先级尝试以下来源：

1. **用户提供**：用户已有院校列表和数据，只需整理成表
2. **公开数据**：各省教育考试院公布的历年投档线
3. **院校官网**：各大学招生网公布的历年录取数据
4. **第三方平台**：高考志愿填报类 APP/网站

数据缺失时的处理：
- 标注 `—` 表示该年份未招生或无数据
- 标注 `*` 并附注数据来源和可靠性说明
- 对于只有部分数据的年份，注明"数据不全，仅供参考"

### 3. 生成表格

根据用户需求生成对应的表格类型：
- **深度分析型**：单校单专业，3年完整数据+趋势
- **横向对比型**：多校同专业，当年数据对比
- **全景扫描型**：多校多专业，冲稳保分层

### 4. 标注评估

每张表必须包含：
- **冲/稳/保** 三级标注
- **安全系数**：你的分数与录取线的差值
- **风险提示**：大小年现象、政策变动、新增/取消专业

## 常见表格配色标记

在 Markdown 表格中使用 emoji 标记：
- 🟢 安全/保底（超线 10 分以上）
- 🟡 适中/可冲（线上下 5 分以内）
- 🔴 危险/冲刺（差 5-20 分）
- ⬆️ 分数/位次上升趋势
- ⬇️ 分数/位次下降趋势
- ➡️ 基本持平
- ⚠️ 数据不全或存疑

## 上海市分数参考

- 总分660（语150+数150+外150+选考3*70） × 0.5 + 专业课 × 1.25
- 特招线：2023年504 / 2024年503 / 2025年待定
- 本科线：2023年405 / 2024年403 / 2025年待定

## Excel 表格生成

当用户需要下载/保存为 Excel 文件时，使用 Python openpyxl 生成 `.xlsx` 格式的对照表。

### Excel 表结构

每个 Excel 包含两个 Sheet：

**Sheet 1 — 近三年录取对比**

| 列 | 字段 | 说明 |
|----|------|------|
| A | 院校名称 | 全称 |
| B | 批次 | 一本/二本等 |
| C | 年份 | 2023/2024/2025 |
| D | 最低录取分 | 当年投档线 |
| E | 最低位次 | 省排名 |
| F | 线差 | 超批次线分数 |
| G | 专业最低分 | 该专业录取最低分 |
| H | 学费（元/年） | 每年学费 |
| I | 你的差距 | 你的分数-录取分，负数用红色 |
| J | 推荐程度 | ★★★ 极力推荐 / ★★ 可考虑 / ★ 保底 |

**Sheet 2 — 冲稳保总览**

| 列 | 字段 |
|----|------|
| A | 院校名称 |
| B | 层级 | 冲刺/稳妥/保底 |
| C | 核心优势 | 一句话卖点 |
| D | 风险提示 | 注意事项 |
| E | 学费范围 | min-max |
| F | 推荐指数 | 1-5星 |

### Excel 格式规范

- **标题行**：深蓝底白字，加粗，14 号字
- **冲刺行**：浅红底（#FFE0E0）
- **稳妥行**：浅黄底（#FFF8E0）
- **保底行**：浅绿底（#E0FFE0）
- **负差距**：红色加粗字体
- **正差距**：绿色字体
- **列宽自适应**：自动调整，最小 12 字符
- **冻结首行**：方便滚动查看
- **边框**：全表格细线边框

### Excel 生成脚本模板

```python
import openpyxl
from openpyxl.styles import Font, PatternFill, Alignment, Border, Side

wb = openpyxl.Workbook()

# === Sheet 1: 近三年录取对比 ===
ws1 = wb.active
ws1.title = "近三年录取对比"

# 样式定义
header_fill = PatternFill(start_color="1F4E79", end_color="1F4E79", fill_type="solid")
header_font = Font(name="微软雅黑", size=14, bold=True, color="FFFFFF")
red_fill = PatternFill(start_color="FFE0E0", end_color="FFE0E0", fill_type="solid")
yellow_fill = PatternFill(start_color="FFF8E0", end_color="FFF8E0", fill_type="solid")
green_fill = PatternFill(start_color="E0FFE0", end_color="E0FFE0", fill_type="solid")
red_font = Font(name="微软雅黑", size=11, bold=True, color="CC0000")
green_font = Font(name="微软雅黑", size=11, color="007A33")
normal_font = Font(name="微软雅黑", size=11)
thin_border = Border(
    left=Side(style='thin'), right=Side(style='thin'),
    top=Side(style='thin'), bottom=Side(style='thin')
)

# 写入表头
headers = ["院校名称", "批次", "年份", "最低录取分", "最低位次", "线差", "专业最低分", "学费(元/年)", "你的差距", "推荐程度"]
for col, h in enumerate(headers, 1):
    cell = ws1.cell(row=1, column=col, value=h)
    cell.fill = header_fill
    cell.font = header_font
    cell.alignment = Alignment(horizontal="center", vertical="center")
    cell.border = thin_border

# 写入数据（示例）
data = [
    ["中国人民大学", "本科一批", 2023, 642, 185, 150, 640, "5000", "+8", "★★★"],
    ["中国人民大学", "本科一批", 2024, 645, 170, 153, 644, "5000", "+5", "★★★"],
    ["中国人民大学", "本科一批", 2025, 648, 155, 158, 647, "5000", "+2", "★★"],
    # ... 更多数据
]

for row_idx, row_data in enumerate(data, 2):
    gap = row_data[8]  # 差距列
    tier = row_data[9]  # 推荐程度
    
    # 选行背景色
    if "★★★" in tier:
        row_fill = green_fill
    elif "★★" in tier:
        row_fill = yellow_fill
    else:
        row_fill = red_fill
    
    for col_idx, value in enumerate(row_data, 1):
        cell = ws1.cell(row=row_idx, column=col_idx, value=value)
        cell.font = normal_font
        cell.alignment = Alignment(horizontal="center", vertical="center")
        cell.border = thin_border
        cell.fill = row_fill
        
        # 差距列特殊颜色
        if col_idx == 9:
            if isinstance(value, str) and value.startswith("-"):
                cell.font = red_font
            elif isinstance(value, str) and value.startswith("+"):
                cell.font = green_font

# 列宽自适应
for col in ws1.columns:
    max_len = max(len(str(cell.value or "")) for cell in col)
    ws1.column_dimensions[col[0].column_letter].width = max(max_len + 4, 12)

# 冻结首行
ws1.freeze_panes = "A2"

# === Sheet 2: 冲稳保总览 ===
ws2 = wb.create_sheet("冲稳保总览")
# ... 类似结构

wb.save("高考志愿对照表.xlsx")
```

## 备选推荐模式

当用户分数达不到目标院校时，自动触发此模式：

### 触发条件
- 用户综合分与目标院校预估线差距 >3 分
- 用户明确问"还有哪些学校"

### 备选规则
1. 同省优先：省内同层次院校排前面
2. 同专业优先：相同或相近专业排前面
3. 学费相近：上下浮动不超 30%
4. 默认推荐 3-5 所，分冲/稳/保三层

### 精简对比表模板

只用一张表说清楚，不写长文：

```
| | 院校A | 院校B | 院校C | 院校D |
|---|---|---|---|---|
| **预估分** | 425-440 | 420-438 | 418-435 | 415-432 |
| **差距** | -6 ↙ | +3 | +10 | +16 |
| **推荐专业** | 法学 | 中文 | 法学 | 数媒 |
| **学费/年** | 0.5万 | 0.5万 | 0.5万 | 0.5万 |
| **录取** | 🟡冲 | 🟢稳 | 🟢稳 | 🟢保 |
```

### 输出规范
- 表头用院校名，不用全称（如"苏州大学"而非"苏州大学学院"）
- 差距列：负数红色、正数绿色
- 不超过 5 列
- 表后跟一句结论，不超 30 字
