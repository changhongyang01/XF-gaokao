# gaokao-admission-table

生成近三年高考录取对照表格，直观对比目标院校/专业的分数线、位次、招生人数。

## 触发方式

在 Codex 中提及以下关键词即自动激活：

- 近三年录取对比、历年分数线、录取位次变化
- 招生计划对比、冲稳保评估
- 综合分换算、录取趋势分析

## 示例对话

> 华东政法、苏大、上大近三年在上海的录取分数对比，政史地538分

> 河南省美术类民办本科横向对比，我的综合分 428.75

> 华中科技大学计算机和武汉大学计算机，近三年在湖北的位次谁更稳

## 安装

将 `gaokao-admission-table/` 整个文件夹复制到：

```
C:\Users\你的用户名\.codex\skills\
```

## 核心能力

- 单校深度分析：三年完整数据 + 趋势箭头
- 多校横向对比：同专业多校排排坐
- **Excel 导出**：一键生成 `.xlsx` 对照表，含学费、推荐程度、冲稳保色标
- 冲稳保标注：🟢 保底 / 🟡 适中 / 🔴 冲刺
- 艺术类专项：文化分 + 专业分 + 综合分同框
- 自动计算：位次涨跌、分数波动、安全系数

## 注意事项

- 分数线数据具有时效性，请以当年各省教育考试院公布为准
- 内置公式以河南省为例，其他省份综合分算法可能不同
