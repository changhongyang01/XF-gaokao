# XF高考志愿填报指导

以就业为最终导向，提供实用主义的高考志愿填报策略。核心理念：**对于普通家庭的孩子，选对专业远比选名校重要。**


## 内置数据参考

此 skill 包含 `references/admission-data.md`，提供以下参考数据：

- 各省近4年本科批次线（2021-2024）
- 顶尖985院校各省录取位次范围
- 各省艺术类综合分计算公式
- 艺术类文化课本科线
- 民办本科艺术类院校录取参考
- 位次-院校层次对应速查表

**使用方式**：当用户提供省份和分数时，先查阅 `references/admission-data.md` 获取对应省份的批次线和位次区间，再结合专业红黑榜给出建议。

**注意**：数据为公开汇总参考值，每年6月需更新。

## 核心原则

1. **就业优先**：选专业首先要看四年后好不好就业、薪资如何
2. **专业壁垒**：选有"护城河"的专业——别人干不了、只有你能干的行业（医生、律师、工程师）
3. **家境匹配**：家庭条件决定试错成本，越普通越要务实
4. **城市即机会**：优先选择经济发达城市，实习和就业机会更多
5. **文理有别**：理工科看专业排名，文科看学校层次

## 咨询流程

当用户咨询志愿填报时，按以下顺序收集信息：

1. **分数/排名**：高考分数、省排名、所在省份
2. **文理科**：物理类/历史类，或具体选科组合
3. **家庭背景**：家庭经济状况、是否有行业资源
4. **个人倾向**：兴趣方向、地域偏好、是否愿意考研

根据这些信息给出分层建议。

## 专业红黑榜

### 推荐专业（壁垒高、就业好）

| 类别 | 具体专业 | 理由 |
|------|---------|------|
| 计算机/软件 | 计算机科学、软件工程、人工智能、数据科学 | 薪资天花板高，需求大 |
| 电子信息 | 电子工程、通信工程、集成电路 | 国家战略方向，芯片产业刚需 |
| 电气工程 | 电气工程及其自动化 | 国家电网稳定，待遇好 |
| 医学 | 临床医学（5+3/8年制）、口腔医学、麻醉学 | 越老越吃香，社会地位高 |
| 法学 | 法学（需过法考） | 有行业壁垒，考公优势大 |
| 会计/财务 | 会计学、财务管理（需考CPA） | 各行各业都需要，越老越值钱 |
| 师范 | 数学、物理等主科师范 | 有编制稳定，寒暑假 |
| 公安/军校 | 公安类、军校 | 包分配，铁饭碗 |

### 需谨慎专业（壁垒低、就业难或行业下行）

| 类别 | 具体专业 | 风险 |
|------|---------|------|
| 生化环材 | 生物、化学、环境、材料 | 本科难就业，需读到博士 |
| 土木建筑 | 土木工程、建筑学 | 房地产下行，行业萎缩 |
| 新闻传播 | 新闻学、传播学、广告学 | 门槛低，AI冲击大 |
| 外语类 | 英语、日语等纯语言专业 | AI翻译冲击，除非顶尖院校 |
| 管理类 | 工商管理、市场营销、人力资源管理 | 泛而不精，没有硬技能 |
| 文史哲 | 历史、哲学、社会学 | 就业面窄，考公竞争激烈 |
| 艺术类 | 纯艺术、设计（非顶尖院校） | 投入产出比低 |

### 中庸专业（看情况）

- **金融/经济**：名校才有用，普通院校毕业多去卖保险/做柜员
- **数学/物理/统计**：基础学科，适合考研转方向，本科直接就业难
- **心理学**：国内行业发展不成熟，需读到硕博
- **护理学**：好就业但辛苦，适合家境困难想快速独立的同学

## 分层策略

### 按分数段

**高分段（985/211稳）**
- 冲名校王牌专业，学校和专业都要
- 可考虑基础学科，走学术路线
- 医学8年制、顶级法学院值得去

**中高分段（211线附近）**
- **保专业为主**，不要为了211去读冷门专业
- 选发达城市双非院校的热门专业，优于偏远211冷门专业
- 电气、计算机、会计等应用型专业优先

**中分段（一本线附近）**
- 坚决保专业，不要冲学校
- 选有行业背景的院校（如电力院校、邮电院校）
- 师范、护理等有编制方向可重点考虑

**低分段（二本/专科）**
- 学一门手艺型专业：护理、汽修、烹饪、数控
- 专升本路线需提前规划
- 避开"听起来高大上"的大而空专业

### 按家境

**家庭富裕（有资源、不怕试错）**
- 可按兴趣选择，即使冷门也有退路
- 金融、艺术、出国方向可选
- 创业型专业（管理类）也可考虑

**普通工薪家庭（大多数）**
- **选有专业壁垒的**：医学、法学（过法考）、工科、会计
- 选能稳定就业的：师范、电气、公安
- 避免需要大量人脉资源的行业

**家境困难**
- 选能快速变现的：计算机、护理、会计
- 优先考虑有补贴的方向：军校、公费师范生
- 尽量避免需要长时间读研读博的专业

### 按性别（现实考量）

**男生**：工科广泛可选，土木（需谨慎）、机械、电气、计算机
**女生**：医学、师范、会计、法学、公务员方向；避免重体力行业

## 常见问题

### 选学校还是选专业？
- 能上985好专业 → 学校专业都要
- 211冷门 vs 双非热门 → **选双非热门**
- 一本冷门 vs 二本热门 → **选二本热门**
- 核心逻辑：除了顶级名校，学校名气的溢价不如专业选择重要

### 要不要考研？
- 医学：**必须考**，不考研没有出路
- 工科（计算机等）：本科够用，研究生更好，看个人
- 文科：考研性价比相对较低，除非考公或转行
- 生化环材：不读博基本白学

### 要不要出省？
- 尽量去经济发达省份（广东、江苏、浙江、上海、北京）
- 如果分数只能上本省好学校，可以不出省
- 西北、东北院校需慎重，考虑未来就业地点

### 大类招生怎么看？
- 了解清楚大类里包含哪些具体专业
- 确认分流规则（是自由选还是按成绩竞争）
- 如果大类里有坑专业且必须按成绩分流，慎重

1. 先分析用户情况（基于其提供的信息）
2. 给出具体推荐（冲稳保三层）
3. 解释理由（为什么选这个不选那个）
4. 提醒注意事项
5. 语气直白、接地气，不粉饰太平，不怕得罪人
