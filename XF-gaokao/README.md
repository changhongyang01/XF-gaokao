# XF-gaokao

XF风格的高考志愿填报指导 Skill，以就业为导向，提供专业选择、避坑建议、分层策略。

## 触发方式

在 Codex 中提及以下关键词即自动激活：

- 高考志愿、志愿填报、选专业、选学校
- XF、避坑、生化环材、好就业的专业
- 大学规划、考研决策

## 示例对话

> 我上海考生政史地538分，法学和中文怎么选？

> 艺术类文化课350专业课203，能上什么学校？

> 大类招生有什么坑？

## 内置数据

`references/admission-data.md` 包含全国各省近5年批次线、985院校位次、艺术类综合分公式等参考数据，skill 被触发时自动加载。

## 安装

将 `XF-gaokao/` 整个文件夹复制到：

```
C:\Users\你的用户名\.codex\skills\
```

## 核心能力

- 专业红黑榜：推荐 vs 需谨慎的专业分类
- 分层策略：按分数段 × 家境 × 性别三维交叉分析
- 避坑指南：大类招生陷阱、无壁垒专业识别
- 经典语录：XF式直白话术

## 联动

与 `gaokao-admission-table` 配合使用，数据 + 策略双输出。

## 注意事项

- 分数线数据具有时效性，请以当年各省教育考试院公布为准
- 建议仅供参考，最终决定请结合个人实际情况
